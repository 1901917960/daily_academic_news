# 每日学术洞察（daily-academic-news）

每天自动抓取当日财经/商业新闻，由 AI 筛选出最有分析价值的一条，从会计学、管理学、金融学的学术视角生成研究报告。配套学术问答、思维库知识图谱、偏好学习与周报等功能，是一个面向学术研究者的每日选题与灵感工具。

## 功能特性

### 每日报告
- **双新闻源**：可切换「国外新闻」（Currents 全球源）或「国内新闻」（华尔街见闻 / 中新网 / 人民网 / 钛媒体 / 爱范儿）
- **AI 主编筛选**：从当日新闻中挑选最有分析价值的一条并生成导语，自动过滤行情播报、公告类新闻
- **时效性保障**：候选新闻按发布时间排序，优先保留最近两天的事件
- **新闻配图**：自动提取新闻封面图；国内新闻直接可读原文，国外新闻附「国内相关报道」检索链接

### 学术分析
- 核心事实、为什么值得关注、制度缝隙、参与方策略、结构类比、核心洞见
- **研究切入点**：2-3 个可研究问题，含理论框架 / 方法建议 / 数据来源 / 目标期刊（可折叠展开）
- **文献启发**：检索 OpenAlex 真实学术文献，基于论文摘要推断「不足与展望」，结合当日新闻衍生研究方向
- **参与方博弈图**：结构化的利益相关方策略可视化（自动避让，标签不遮挡）
- **报告导出**：一键导出 Markdown；提供「完整 / 精简」两种视图

### 学术问答
- 基于当日新闻的多轮追问，**流式输出**（打字机效果）
- 选中任意文字即弹出「追问」按钮，支持对话树分叉与目录导航
- 自动注入知识库上下文，可询问「我学过哪些……」类问题
- 长回答可折叠，出错可重试

### 思维库（知识图谱）
- 知识点自动沉淀（来自每日报告与追问对话），**分级浏览**：分类总览 → 具体知识点
- 力导向动态布局：支持拖拽 / 缩放 / 平移，收敛后自动停止节省资源
- **双模式检索**：精确（按名称）+ 模糊（AI 语义匹配）
- 每个知识点可查看**学术概念**与**通俗解释**（AI 生成并缓存）
- **AI 关联推断**：自动发现知识点之间的联系并标注关系说明；标注可「全显」或「仅点击显示」
- 节点与连线的增删改（右键菜单）、知识点重命名与分类调整

### 偏好学习
- 点击「确认本日」= 喜欢（+1），重新生成报告 = 不喜欢（-1）
- 生成报告时自动按偏好优先选材（同等分析价值下）
- **偏好记录库**：查看权重、手动加减、自定义关注方向、学习历史回溯

### 其他
- **周报**：聚合多日报告，AI 归纳本周主题、趋势与下周关注
- **数据管理**：存储占用统计、超期数据自动清理、JSON 备份导出与导入恢复
- **深色模式**、**日历选择报告日期**、**每日浏览器提醒**、访问码保护

## 技术栈

| 层 | 技术 |
|----|------|
| 前端 | Vue 3 + Vite（组合式 API） |
| AI | DeepSeek API（分析 / 问答 / 概念 / 关系 / 检索） |
| 文献 | OpenAlex API（免费开放学术数据库） |
| 新闻 | Currents API + 国内 RSS 源 |
| 部署 | EdgeOne Makers 边缘函数（API 代理 + 访问码校验） |
| 测试 | Vitest（纯函数单元测试） |

## 本地开发

```bash
npm install
```

在项目根目录创建 `.env`：

```
DEEPSEEK_API_KEY=你的 DeepSeek 密钥
CURRENTS_API_KEY=你的 Currents 密钥
ACCESS_CODE=自定义访问码
```

```bash
npm run dev      # 启动开发服务器
npm test         # 运行单元测试
npm run build    # 生产构建
```

> 开发环境下密钥由 Vite 代理在 Node 进程注入，不会进入前端产物；开发环境无需输入访问码。

## 部署（EdgeOne Makers）

1. 将本仓库推送到 GitHub / GitLab / CNB，在 [EdgeOne Makers](https://pages.edgeone.ai/zh) 控制台导入
2. 在「项目设置 → 环境变量」配置（与本地 `.env` 同名）：`DEEPSEEK_API_KEY`、`CURRENTS_API_KEY`、`ACCESS_CODE`
3. 构建命令 `npm run build`，输出目录 `dist`（已写入 `edgeone.json`）
4. 部署完成后将网址与访问码分享给使用者，首次使用需输入访问码

前端所有请求统一走同源代理（`/api/ai`、`/api/news`、`/api/rss`、`/api/papers`），代理实现在 `edge-functions/` 目录，API Key 仅保存在服务端环境变量中。

> 注意：`edgeone.json` 中的 `@rolldown/binding-linux-x64-gnu` 版本号需与 rolldown 当前版本一致，升级依赖后请同步修改。

## 目录结构

```
src/
  api/            接口封装（新闻 / 分析 / 问答 / 文献 / 关系 / 概念 / 检索 / 周报）
  components/     页面组件（报告 / 问答 / 思维库 / 设置 / 数据 / 周报 / 日历等）
  composables/    组合式逻辑（力导向图、检索、概念面板）
  utils/          纯函数工具（含单元测试）
  storage.js      localStorage 数据层
edge-functions/   EdgeOne 边缘函数（API 代理 + 访问码校验）
edgeone.json      部署配置（SPA 回退、输出目录、依赖安装）
```

## 数据说明

所有数据（报告、对话、知识图谱、偏好）保存在**浏览器 localStorage**，各用户数据独立、互不影响，服务端不存储任何用户数据。数据管理面板支持 JSON 备份导出与导入恢复，应用会自动清理超过保留期的数据（报告 30 天、对话 90 天）。
